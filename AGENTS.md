## Cursor Cloud specific instructions

This is a Next.js 14 single-page portfolio website with no backend, database, or external API dependencies.

**Single service:** Next.js dev server (`npm run dev`) on port 3000.

**Standard commands** (see `package.json` scripts):
- Dev: `npm run dev`
- Lint: `npm run lint`
- Build: `npm run build`

**Notes:**
- No `.env` files or secrets are required.
- The page uses keyboard-driven navigation (arrow keys + Enter) for the interactive terminal menu — useful context for manual testing.
